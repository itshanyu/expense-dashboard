# 記帳 skill

## 觸發條件

本 skill 只在**記帳討論串**（thread ID `1551881517838635018`，靈境 Liminal 伺服器）生效。其他頻道/討論串/私訊完全忽略本 skill 的存在。

## 訊息解析

1. 訊息必須以「數字」開頭才處理（例：`400 午餐`、`350 大稻埕咖啡廳`、`1200.5 超商`）。
2. 第一個數字 = 金額（必須 > 0）；數字之後的所有文字 = 備註。
3. **不是數字開頭的訊息（例：「今天好累」「測試」）**：完全忽略——不記帳、不回覆、不引用、不反應。照常過一般對話流程即可。

## 分類（AI 判斷）

依備註語意從以下 11 個分類選一個，無法判斷時用「其他」：

```
餐食、飲料、交通、旅遊、娛樂、購物、學習、醫療、保險、稅務、其他
```

## 執行動作

解析與分類完成後，呼叫（單行指令）：

```bash
/Users/apple/isis/wiki/投資理財/記帳系統/venv/bin/python /Users/apple/isis/wiki/投資理財/記帳系統/scripts/append_expense.py --amount <金額> --category <分類> --note "<備註>" --date <今天 YYYY-MM-DD 台北時區>
```

環境變數 `GOOGLE_APPLICATION_CREDENTIALS` 與 `EXPENSE_SHEET_ID` 已由設定檔提供；若腳本回報缺少，告知使用者「記帳環境還沒設定好」，不要假造成功。

## 回覆

- 成功：簡短一行確認，格式「✅ 金額｜分類｜備註」，例：`✅ 400｜餐食｜午餐`。不要加長篇解釋。
- 失敗：一行回報「❌ 記帳失敗：<腳本錯誤訊息>」。

## 邊界

- 金額 ≤ 0 或純數字無備註之外的畸形輸入：若金額解析失敗則視同非記帳訊息忽略。
- 同一訊息多筆金額（例：`400 午餐 150 咖啡`）：只取第一個數字，其餘全部當備註，不要拆成兩筆。
- 不做編輯/刪除；使用者要改資料直接改 Google Sheets。
- 本 skill 不改變葛斯的其他人格與功能。
